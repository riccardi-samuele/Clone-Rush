# Clone Rush — pre-submission audit, 12 October 2026

## Result

The two ad-free technical packages pass the checks below. **Do not submit
either package yet:** rights for inherited *Jumping Clones* material remain
unverified. Passing runtime checks does not establish permission to distribute
those levels or the source-derived physics data.

The audio restoration has a deterministic unit check, but an actual iPhone/Safari
interruption and CrazyGames App safe-area behavior cannot be certified from
Chromium emulation. The installed Playwright WebKit cannot launch here because
the host is missing its multimedia libraries; this is an unrun browser check,
not evidence of a game failure. CrazyGames' and GamePix's private iframe
previews are also unavailable before the game is uploaded to their accounts.

## Rights gate

The original *Jumping Clones* listing credits **Robert Alvarez**. This
repository's `ASSETS.md` identifies inherited physics metadata; the cleanup
regression explicitly verifies that the original maps retain their geometry.
The local predecessor build has no game-specific redistribution license or
permission document. The first public Clone Rush Git commit also contains the
old derivative audio files, although the current runtime uses newly synthesized
audio. None of these findings proves ownership or authorization. GamePix says
the submitting developer is responsible for code, assets and template rights;
CrazyGames' developer terms likewise require ownership or necessary rights.

Before submission, obtain and record an applicable permission for the inherited
code/data/levels, or replace those parts with independently authored material
and repeat the campaign and browser checks. Decide separately whether to clean
the public Git history with the repository owner; doing so would require a
history rewrite and would not itself resolve the runtime rights question.
