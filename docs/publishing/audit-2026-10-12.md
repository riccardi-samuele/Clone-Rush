# Clone Rush — pre-submission audit, 12 October 2026

## Result

The two ad-free technical packages pass the checks below. The provenance
assessment in the original version of this report was corrected on 13 October:
the map cleanup contract describes the authored Candy Sky campaign, not the
historical predecessor's maps. Current publication status is recorded in
`readiness-2026-10-13.md`.

The audio restoration has a deterministic unit check, but an actual iPhone/Safari
interruption and CrazyGames App safe-area behavior cannot be certified from

the host is missing its multimedia libraries; this is an unrun browser check,
not evidence of a game failure. CrazyGames' and GamePix's private iframe
previews are also unavailable before the game is uploaded to their accounts.

## Correction of the provenance assessment — 13 October 2026

The earlier report incorrectly treated `docs/cleanup/map-contract.json` as a
baseline of the historical predecessor's maps. It is a baseline of Candy Sky
immediately before cleanup. `tools/candy-sky/create-campaign.mjs` defines all
32 current native island maps and the ending. The old tile-map format is not
supported. The cleanup test preserves those authored Candy Sky layouts.

The runtime is implemented in the current Phaser/Matter modules under `src/`;
the predecessor's packaged engine and game scripts are not part of the upload.
`public/data/catalog.json` still contains historically sourced actor metadata,
as recorded in `ASSETS.md`. That is a narrower finding than inherited runtime
code or campaign layouts, and the previous assertion about inherited maps is
withdrawn. This technical audit does not independently certify legal ownership.
The submitter must make the rights declarations required by the portal.
